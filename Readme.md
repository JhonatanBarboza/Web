# SCC0219 – Introdução ao Desenvolvimento Web

Repositório contendo as atividades e o projeto desenvolvidos durante a disciplina **SCC0219 – Introdução ao Desenvolvimento Web** da Universidade de São Paulo (USP/ICMC).

## Objetivos

Aplicar conceitos fundamentais de desenvolvimento Web, incluindo:

- HTML, CSS e JavaScript;
- Design responsivo;
- Node.js e Express;
- APIs REST;
- Integração com banco de dados PostgreSQL;
- Desenvolvimento Full Stack.

## Projeto 1 
O **Caderno+** é uma aplicação web desenvolvida para auxiliar estudantes na organização e no estudo de anotações feitas em sala de aula. A plataforma permite o upload de fotos da lousa, PDFs e outros materiais, utilizando Inteligência Artificial para transcrever o conteúdo e gerar resumos, explicações e questões de revisão. O objetivo é transformar registros estáticos em um ambiente de estudo organizado, acessível e interativo, facilitando a revisão do conteúdo e promovendo um aprendizado mais eficiente.

## Projeto 2
O **Poções e Soluções** é uma aplicação web desenvolvida para uma loja fictícia de poções mágicas. O sistema oferece um catálogo de produtos para os clientes e uma área administrativa para gerenciamento das poções, permitindo cadastrar, listar e remover itens. O projeto utiliza um Web Service para integrar o front-end ao back-end, proporcionando uma interface dinâmica para visualização dos produtos e aplicando conceitos de desenvolvimento web, banco de dados e APIs.

## Projeto Final 

O **Painting Service** é uma aplicação web desenvolvida para modernizar a presença digital de uma empresa de pintura residencial e comercial. A plataforma permite que clientes conheçam os serviços oferecidos, visualizem projetos realizados, solicitem orçamentos e realizem agendamentos de forma prática e intuitiva.

Além da área pública, o sistema conta com um painel administrativo para gerenciamento de conteúdos, portfólio, avaliações, promoções e agendamentos. O projeto foi desenvolvido aplicando conceitos de desenvolvimento Full Stack, incluindo autenticação de usuários, integração com banco de dados, APIs REST e uma interface responsiva voltada para proporcionar uma boa experiência tanto para clientes quanto para administradores.
